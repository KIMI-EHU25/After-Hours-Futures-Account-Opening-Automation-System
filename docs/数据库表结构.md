# 数据库表结构说明

## 1. 数据库基本信息

- 数据库管理系统：PostgreSQL
- 数据库名：`postgres`
- Schema（模式）：`openaccount`
- 完整位置：`postgres.openaccount`
- 当前 Alembic 版本：`40594f81ffae`
- 当前表数量：17 张（包含 Alembic 自身使用的 `alembic_version` 表）
- 记录日期：2026-09-11

本文档依据当前实际数据库结构整理。访问表时应指定 `openaccount` 模式，例如：

```sql
SELECT * FROM openaccount.users;
```

符号说明：

- `PK`：主键（Primary Key）
- `FK`：外键（Foreign Key）
- `UQ`：唯一约束（Unique Constraint）
- `NOT NULL`：不允许为 `NULL`
- `NULL`：允许为 `NULL`
- `IDENTITY`：由 PostgreSQL 自动生成整数值
- `SEQUENCE`：通过 PostgreSQL 序列自动生成整数值

> 注意：`addinfoanswers` 中包含大小写混合的列名。直接编写 SQL 时，这些列名需要用双引号包裹，例如 `"idCardNumber"`。

## 2. 表关系概览

- `users` 是四张业务答题表的父表。
- `launderingbackanswers.uid`、`addinfoanswers.uid`、`questionanswers.uid`、`choosefuturesanswers.uid` 均关联 `users.uid`。
- 三组问卷配置均由题目表和选项表组成；删除题目时，对应选项通过 `ON DELETE CASCADE` 级联删除。
- `citycodes.province_code` 关联 `provincecodes.province_code`；删除省级代码时，对应城市代码通过 `ON DELETE CASCADE` 级联删除。
