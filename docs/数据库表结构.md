# 数据库表结构说明

## 1. 数据库基本信息

- 数据库管理系统：PostgreSQL
- 数据库名：`postgres`
- Schema（模式）：`openaccount`
- 完整位置：`postgres.openaccount`
- 当前 Alembic 版本：`c70cdb6870d2`
- 当前表数量：18 张（包含 Alembic 自身使用的 `alembic_version` 表）
- 记录日期：2026-09-20

本文档基于 2026-09-20 的数据库结构记录，并按后续字段变更更新；它不是实时数据库查询结果。模型和迁移定义可静态核对，实际数据库版本、约束名称及默认值应以目标数据库查询为准。访问表时应指定 `openaccount` 模式，例如：

```sql
SELECT * FROM openaccount.users;
```

符号说明：

- `PK`：主键（Primary Key）
- `FK`：外键（Foreign Key）
- `UQ`：唯一约束（Unique Constraint）
- `NOT NULL`：不允许为 `NULL`
- `NULL`：允许为 `NULL`
- `IDENTITY`：由 PostgreSQL 自动生成整数值
- `SEQUENCE`：通过 PostgreSQL 序列自动生成整数值

## 2. 表关系概览

- `users` 是四张业务答题表及 `refreshtokens` 的父表。
- `launderingbackanswers.uid`、`addinfoanswers.uid`、`questionanswers.uid`、`choosefuturesanswers.uid`、`refreshtokens.uid` 均关联 `users.uid`。
- 三组问卷配置均由题目表和选项表组成；删除题目时，对应选项通过 `ON DELETE CASCADE` 级联删除。
- `citycodes.province_code` 关联 `provincecodes.province_code`；删除省级代码时，对应城市代码通过 `ON DELETE CASCADE` 级联删除。
