# 所有字段整理

本文档按照当前 `service-js/app/script/main.js` 中的页面注入数据结构整理，并补充其与后端 POST 接口的对应关系。

说明：

- 两个已经停用的只读字段未收入本文档。
- `contactnumber`（联系电话）是当前仍在使用的字段。
- 下方 `data` 只保存页面注入数据，因此不包含 `uid`。
- 将数据提交到后端时，每个 POST 请求体都需要另外加入 `uid`。
- 日期通过 JSON 传输时使用 `YYYY-MM-DD` 字符串，例如 `2026-03-03`。
- 标记为可选的字段既可以传 `null`，也可以不传。

## 接口对应关系

| 数据分组 | 请求接口 |
| --- | --- |
| `launderingBack` | `POST /api/launderingBack/answer` |
| `addInfo` | `POST /api/addInfo/answer` |
| `question` | `POST /api/question/answer` |
| `chooseFutures` | `POST /api/chooseFutures/answer` |

提交时可以通过对象展开语法为对应页面数据增加 `uid`，例如：

```js
const requestBody = {
    uid: 1,
    ...data.launderingBack
};
```

## 可选字段

以下字段可以传 `null` 或不传：

- `idCardValidPeriodStart`
- `idCardValidPeriodEnd`
- `emailAddress`
- `intermediaryName`
- `intermediaryCode`
- `referencePersonCode`
- `referencePersonName`
